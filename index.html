Hämtar Text-TV…

Du kan använda samma HTML-fil på datorn, på iPhone och iPad. Vilket sätt som passar bäst beror på om filen ligger på webben eller bara finns lokalt i appen Filer.

Rekommenderas · HTTPS

🌐 Lägg till webbsidan som app på iPhone eller iPad

  1. Ladda upp din enda HTML-fil som index.html till ett valfritt webbhotell med HTTPS.
  2. Öppna webbadressen i Safari på iPhone eller iPad.
  3. Tryck på Dela (fyrkanten med uppåtpil). Välj Lägg till på hemskärmen. Hittar du inte alternativet, bläddra längre ned i delningsmenyn.
  4. Aktivera Öppna som webbapp om valet visas. Namnge den Väderlek och välj Lägg till.
  5. Öppna Väderlek från hemskärmen. Du får ett app-liknande fönster och samma uppdaterade webbplats som på datorn .

Fördel: Du behöver inte föra över nya filer vid uppdateringar, utan byter bara index.html på webbhotellet.

Alternativ · Enbart lokal fil

📁 Öppna HTML via appen Genvägar

  1. Spara Vader.html i Filer på din iPhone eller iPad.
  2. Öppna artikeln Open HTML files with JavaScript och följ förklaringen för Apple Genvägar.
  3. Du kan testa den delade genvägen Open HTML file, men granska dess åtgärder innan du använder den.
  4. Välj HTML-filen i genvägen och kontrollera att sidan öppnas och att JavaScript körs.
  5. I appen Genvägar, öppna genvägens alternativ och välj Lägg till på hemskärmen; ge ikonen namnet Väderlek.

Begränsning: En lokal file:- eller data:-sida kan få problem med YouTube, väder-API:er och vissa bilder. Därför är HTTPS-alternativet bättre.

Vad betyder PWA?

PWA (Progressive Web App) är en webbplats som kan bete sig som en app, till exempel med en egen ikon, app-liknande fönster och ibland stöd för offlineanvändning. Den här versionen ligger medvetet i en enda HTML-fil. Den kan läggas på hemskärmen men är inte en fullständig offline-PWA, eftersom separat manifest och service worker saknas. Den behöver dessutom internet för aktuella väderprognoser, bilder och Text-TV.

Dator: Publicera på HTTPS, öppna adressen i webbläsaren och spara som bokmärke. Du behöver ingen appinstallation.
